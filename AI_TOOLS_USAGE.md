# AI Tools Usage Summary

This project was built through collaboration between the developer and an AI assistant (Copilot SDK in VS Code).

## How We Worked Together

- **Planning**: We discussed the project requirements and agreed on a simple, free-technology stack that could be built and demonstrated without any paid services.
- **Backend Development**: The AI assistant generated the FastAPI backend code including authentication, role management, listings, messaging, and WebSocket signaling for calls. The developer reviewed and confirmed the design.
- **Frontend Development**: The AI assistant created all React Native screens (Login, Register, Home, Listings, Messages, Call, Profile) and the API service layer. The developer provided feedback on screen flow and UI simplicity.
- **Documentation**: The AI assistant drafted the README, technical documentation, and this AI usage summary. The developer reviewed for accuracy.
- **Script Generation**: The AI assistant created the step-by-step demonstration video script (script.md) for the final walkthrough.

## Contribution Split

- **AI Assistant**: Wrote initial code structure, generated all source files, suggested architecture, prepared documentation and demo script.
- **Developer**: Provided requirements, reviewed all code, made decisions on stack and features, will execute setup commands, run the application, and record the demonstration video.

## Tools Used

- Copilot SDK in VS Code (AI assistant for code generation and documentation)
- NVIDIA Nemotron free API (available if needed for additional AI support)

Both parties contributed to the final deliverable. The developer understands and can independently explain all code, architecture, and technical decisions.
